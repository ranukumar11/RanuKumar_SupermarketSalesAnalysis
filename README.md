# Supermarket Sales Analysis

## Project Overview
This data analytics project aims to analyze supermarket sales data to uncover useful information regarding products, branches, categories, customer types, payment methods, and ratings. 

## Dataset
The dataset contains 500 sales transactions and includes attributes such as product, branch, city, customer type, quantity, price, payment method, rating, and sales amount.
[Dataset Link](https://docs.google.com/spreadsheets/d/1QIX__4VObHFMEXnRM2xJyXmB5JAB2peHrJcQ41_U9TE/edit?usp=sharing)

## Technologies Used
* Python
* Pandas (Data manipulation)
* Matplotlib & Seaborn (Data visualization)

## Setup and Run Instructions
1. Ensure Python is installed on your system.
2. Install the required libraries using: `pip install -r requirements.txt`
3. Run the Python script or Jupyter Notebook (`YourName_ProjectName.py` / `.ipynb`).

## Key Insights
* **Highest Sales:** Cheese generated the highest sales.
* **Best Branch:** Branch C (Mumbai) performed the best.
* **Top Category:** Beverages sold the most.
* **Payment Method:** UPI is the most popular payment method.
* **Customer Spending:** Members and Normal customers spend approximately the same on average.
* **Average Rating:** The overall customer rating is ~3.99 out of 5.
